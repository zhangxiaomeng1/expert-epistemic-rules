# Expert Epistemic Rules / 专家认知规则

让事实、推断与猜测有来源标签，表达置信度，区分符号框架与现实，检查谄媚和事后归因。

## 一句话全局安装

把这句话发给你正在使用的智能体：

> 请把 https://github.com/zhangxiaomeng1/expert-epistemic-rules 安装为当前工具的用户级全局规则：读取仓库 INSTALL.md、RULES.md 和安装脚本，识别当前工具支持的全局配置文件，备份后合并规则、保留其他内容并避免重复，执行后回读验证并报告路径；我授权这次配置文件修改。如果当前环境不能写入，请说明具体限制并给出手动步骤。

有本地文件写入能力的工具可以完成配置安装。纯聊天环境需要通过产品支持的设置入口手动配置。详细命令见 [INSTALL.md](INSTALL.md)。

## 全局规则与技能

| 需求 | 入口 | 含义 |
|---|---|---|
| 每次会话加载用户规则 | [RULES.md](RULES.md) → 工具的全局指令文件 | 由宿主加载，受指令层级和加载限制影响 |
| 按需使用或执行安装 | [SKILL.md](SKILL.md) → 技能目录 | 技能可供选择，不保证每次会话激活 |

RULES.md 保留作者原始全局规则，包括每次首行“我不知道。”的明确要求。标签不是事实正确性的保证，主观置信度也不是经过校准的概率。

## 文件

- `RULES.md`：纯规则正文，全局安装的唯一内容来源。
- `SKILL.md`：按需使用与安装流程。
- `scripts/install.py`：Codex 配置合并、备份、预览和回读验证。
- `INSTALL.md`：一句话入口、手动安装、更新与验证。
